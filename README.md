# Weather-app

`Weather-app` является шаблоном для вывода погоды в браузер, беря данные из [API](https://openweathermap.org/api).

## Как проверить

Перед началом работы с проектом необходимо установить `Node.js v22.21.1`. 

После этого необходимо добраться до корневой папки проектоа в консоли и написать следующее:
```
npm start
```

## Как редактировать

`App.js` - корневая компонента проекта, объединяющая все его составляющие.

`index.css` - файл стилей проекта.

`assets/icons` - папка с SVG-иконками для визуального отображения состояния погоды.

`components/CityComponent.jsx` - компонета, которая является титульным элементом для ввода нужного города.

`components/WeatherComponent.jsx` - компонента отрисовки основной информации о погоде в выбранном городе.

`components/WeatherInfoComponent.jsx` - компонента, вложенная в `WeatherComponent`, отображающая дополнительную информацию о погоде.

## Цель проекта

Проект был написан в образовательных целях в процессе занятий в школе "Третье место"
